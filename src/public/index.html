Blocked internet addresses (attackers / knockers)

AddressNote on routerUnblocks in
Block a single address or a range (/16 to /32). Everything from it to the router and the internal network is dropped, and local devices cannot reach it. Also available as a Block button next to outside addresses in Destinations, Security and the device panel. Never blockable: private addresses, this router's own public address, the ISP gateway and the DNS servers in use.

Blocked from the internet

DeviceNetworkNote on routerUnblocks in
A blocked device keeps its local network access (printers, file server, DHCP) but cannot reach the internet. To block someone, use the Block button next to a device in Live, Abuse or Security, or in the device panel. Blocking works by address: a phone that changes its address needs a fixed (static) lease.

General

Bandwidth control (MikroTik queues)

Limits apply to internet traffic only (queues are tied to the internet interface ); LAN traffic is never limited. Each group gets a default rate per device, so every new device is covered automatically. Individual devices or users can be given a different profile (above the group rule) manually or by auto-throttle. Nothing is enforced until you turn the master switch on and press Apply.
