# Code of Conduct

We want this project to be welcoming to everyone, whatever their language, background, experience or role.

## Our standards

* Be kind and patient; assume good intent. People here write in a second language, read right-to-left, or are brand new to networking.
* Give and accept constructive feedback; criticize code, not people.
* Keep discussions focused on the project. No harassment, discrimination, personal attacks, or sharing of others' private information.
* Do not post real network details, passwords, keys or customer data in issues (see [SECURITY.md](SECURITY.md) for security reports).

## Enforcement

Maintainers may edit, hide or remove comments, issues and pull requests that break these standards, and may block repeat offenders. Report problems to the maintainers at Kish IT (<https://kish-it.com>); reports are handled in confidence.

This code is adapted from the Contributor Covenant, version 2.1 (<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>).
